# Plan: Add the x86 GDBserver Recipe and Binary

*Distilled: 2026-08-07*

## Summary

Add GNU GDBserver 16.3 as a reproducible static 32-bit x86 executable. Use a
tool-owned, checksum-pinned full-system x86 smoke guest so a real Remote Serial
Protocol exchange and inferior attach are proven independently of host 32-bit
compatibility or QEMU user-mode ptrace behavior.

Execute this plan after `20260807_14-x86-tcpdump.md` establishes the x86
artifact and contributor contracts.

## Problem

GDBserver is distributed for the other architectures but not x86. A version
command is insufficient for this tool, and user-mode emulation cannot be
assumed to implement the ptrace and asynchronous behavior required by a real
inferior on every host.

## Scope

In scope:

- Add `recipes/gdbserver/x86/` with GNU-signed GDB 16.3 source, the established
  GDBserver-only profile, licenses, x86 link inventory, and static smoke helpers.
- Pin and verify an official versioned Alpine x86 kernel in a tool-owned
  `vm.lock`, cache it outside the repository, and boot a generated diskless
  initramfs with `qemu-system-i386`.
- Add `artifacts/x86/gdbserver` and its catalog, checksum, README, and TRUST
  records after a real RSP exchange passes.

Out of scope:

- Building the GDB client, in-process agent, binutils, Python, Guile, or other
  disabled GDB components.
- Sharing VM machinery across recipes, committing a kernel/VM disk, or relying
  only on native x86-64 compatibility mode.
- Changing existing GDBserver recipes or making an independent provenance claim.

## Design

Port the established GDBserver source, configure, static-link, archive
inventory, and RSP helper design. Add the explicit
`-march=i686 -msse2 -mfpmath=sse` baseline and require the candidate and both
helpers to be stripped static ELF32 little-endian x86 `ET_EXEC` files with no
interpreter or `DT_NEEDED`. Compile both helpers with strict warnings, strip
them before export, and subject them to the same host ELF/stripping validator
as the candidate. Keep diagnostics in the warning-clean source and VM logs
rather than retaining symbol tables in the generated initramfs.

During implementation, select one official versioned Alpine x86 kernel only
after its published configuration and an evidence boot prove the required PC
machine, serial console, initramfs, and 32-bit x86 support. Record its literal
HTTPS URL, release, filename, checksum, and authentication limitation. Boot a
generated initramfs with `qemu-system-i386` and a fixed CPU model exposing at
least the documented CMOV/SSE2 baseline. PID 1 must attach GDBserver to a real
target, observe a valid stop reply, process the kill packet, and shut down with
a bounded success marker. Preserve build output so VM-test fixes do not trigger
another compile.

## Affected Components

- `recipes/gdbserver/x86/`: add authenticated source, build scripts, VM lock,
  initramfs/RSP helpers, licenses, inventory, and documentation.
- `artifacts/x86/gdbserver`: add the validated executable.
- `recipes/catalog.tsv`: enable `(gdbserver, x86)`.
- `artifacts/SHA256SUMS`: add the sorted exact digest.
- `README.md`: add x86 GDBserver availability and rebuild support.
- `TRUST.md`: record GNU authentication, kernel limitation, committed recipe
  validation, and `None` for independent evidence.

## Implementation Sequence

1. Require the committed x86 builder and evidence-select one official x86
   kernel/CPU/machine combination; pin it before recipe execution.
2. Port the recipe and helpers, establish exact x86 archive ownership, and run
   syntax plus strict warning checks before compilation. Preserve the current
   ARMv7 behavior that strips and validates both helpers before VM assembly.
3. Announce the expected emulated duration, build once, retain the output, then
   run version, ELF, kernel, and bounded full-system RSP validation.
4. Add the artifact and shared records only after the VM success marker;
   validate, commit, and push explicit paths.

## Validation

- Run offline GNU PGP verification, shell syntax and C warning checks,
  `git diff --check`, and `./validate.sh`.
- Run `./build.sh gdbserver x86` once; require exact version, complete link
  inventory, verified kernel bytes, and the real attach/stop/kill exchange.
- Inspect candidate and helpers with `file`/`readelf`; require ELF32
  little-endian x86, the explicit CPU baseline, `ET_EXEC`, no interpreter, and
  no `DT_NEEDED`, debug sections, or full symbol tables.
- Verify the installed artifact checksum and rerun the full-system smoke test
  against the installed bytes without recompiling.

## Success Criteria

- The committed binary is a stripped static x86 GDBserver built from
  authenticated tracked source and the immutable x86 builder.
- A declarative checksum-pinned full-system guest proves a real RSP inferior
  exchange on 32-bit x86.
- Existing GDBserver artifacts and assurance records remain unchanged.
