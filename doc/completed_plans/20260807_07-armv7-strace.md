# Plan: Add the ARMv7 strace Recipe and Binary

*Distilled: 2026-08-07*

## Summary

Add strace 6.16 as a reproducible static ARMv7 executable with its native
personality only. Port the AArch64 recipe's full-system ptrace test to a pinned
ARMv7 kernel and QEMU 32-bit `virt` guest so known syscalls are decoded by a
real ARMv7 kernel.

## Problem

strace is distributed for AArch64 and x86-64 but not ARMv7. QEMU user mode does
not provide the target ptrace behavior needed for the repository's functional
test, so a version-only or configure-only port would not satisfy the artifact
contract.

## Scope

In scope:

- Add `recipes/strace/armv7/` using the existing tracked strace source,
  checksum-only authentication, bundled UAPI profile, licenses, link inventory,
  static smoke target, and PID 1 ptrace harness.
- Pin and verify an official versioned Alpine ARMv7 `vmlinuz-lts`, proven to
  boot QEMU `virt`, for a generated diskless validation guest.
- Build and commit `artifacts/armv7/strace` with catalog, checksum, README, and
  TRUST records.

Out of scope:

- Enabling compatibility personalities, stack unwinding, libiberty, or SELinux
  contexts, or updating strace.
- Sharing VM definitions across recipes or committing VM/kernel images.
- Adding an independent rebuild service or provenance attestation.

## Design

Preserve the AArch64 source/configure policy: bundled Linux UAPI headers,
`--enable-mpers=no`, no external unwind/libiberty/SELinux dependencies, a
linker map, and complete archive reconciliation. Determine and assert the exact
ARMv7 native-personality feature line produced by this locked build; do not
describe 32-bit ARM as a compatibility personality.

Translate the recipe to `linux/arm/v7`, the ARMv7 builder and compiler paths,
and `artifacts/armv7/strace`. Guest and host validation must require stripped
static ELF32 little-endian ARM hard-float `ET_EXEC` files with no interpreter
or `DT_NEEDED` for strace and both helpers.

Use a tool-owned lock for an official checksum-pinned Alpine ARMv7
`vmlinuz-lts`, selected only after its published configuration and an evidence
boot prove QEMU `virt`, PL011 console, and initramfs support. Boot the generated initramfs with
`qemu-system-arm -machine virt,highmem=off -cpu cortex-a15`. The PID 1 harness
must run strace against a direct child and prove the known `openat`, marker
`write`, and `exit_group(0)` calls before emitting its success marker. Preserve
the compiled output for late VM-test corrections. Record the maintainer-built
recipe validation separately from the absence of independent rebuild evidence.

## Affected Components

- `recipes/strace/armv7/*`: add the complete recipe, VM lock/harness, source,
  licenses, and link evidence.
- `artifacts/armv7/strace`: add the validated executable.
- `recipes/catalog.tsv`: enable `strace, armv7`.
- `artifacts/SHA256SUMS`: add the sorted digest.
- `README.md`: list the ARMv7 artifact and recipe.
- `TRUST.md`: add source, VM kernel, and artifact assurance records.

## Implementation Sequence

1. Require the ARMv7 r2 builder and resolve/pin an official versioned Alpine
   ARMv7 `vmlinuz-lts` proven to boot the selected QEMU machine.
2. Port the AArch64 build and VM helpers, verify compiler triplet/archive
   ownership, and run syntax/C warning checks.
3. Announce the expected duration before the emulated compile. Build once,
   retain the valid layer and diagnostics, then run exact version/feature and
   full-system ptrace checks.
4. Add the artifact and shared live records after success, stage explicit
   paths, run repository validation, commit, and push.

## Validation

- Run warning-clean compilation of the smoke helpers, `./validate.sh`, and
  `git diff --check`.
- Run `./build.sh strace armv7`; require exact source checksum, full link
  inventory, exact version/native feature line, and the VM syscall assertions.
- Inspect all three ARMv7 executables using `file` and `readelf`, and verify the
  installed strace checksum against the complete manifest.
- Confirm existing strace bytes and assurance records remain unchanged and no
  independent rebuild or attestation claim was added.

## Success Criteria

- A fresh checkout builds the committed stripped static ARMv7 strace from the
  tracked source and immutable builder.
- A checksum-pinned ARMv7 full-system guest proves real direct-child ptrace and
  exact syscall decoding.
- Existing strace profiles, artifacts, and assurance records remain unchanged.
